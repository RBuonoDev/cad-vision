# 3DE

**3DE** é um ambiente CAD 3D paramétrico para visualizar, criar e analisar modelos mecânicos.

A interface web está disponível em: https://3de-cad.streamlit.app/

## Recursos

- Modelagem CAD 3D paramétrica
- Visualização e edição de peças
- Fluxo voltado à análise de desenhos mecânicos
- Aplicação web acessível pelo navegador

## Executar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
